# Security reporting

Please report a vulnerability privately to <lucian.pavel@pawelworks.com> with the subject `SkillLatch security report`. Include a minimal reproduction and version or commit identifier. Do not post working exfiltration payloads or personal data in a public issue.

This is an early prototype. It has no independent security audit or supported production deployment. The [threat model](docs/THREAT_MODEL.md) states what its decisions do and do not cover. We will acknowledge a report and coordinate disclosure with the reporter; no response-time guarantee or bounty program is offered.
