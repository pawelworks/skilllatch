# Governance

SkillLatch currently has one maintainer: Pavel Mihai Lucian, PAWELWORKS S.R.L. Project decisions are recorded in public issues or pull requests. There is no steering committee, second maintainer, foundation sponsor, or independent security team at this stage.

Changes that affect the example policy format, decision meanings, or security claims should be proposed publicly and allowed at least two weeks for comment. Routine documentation and implementation changes normally remain open for seven days unless a clearly explained urgent fix is needed. A maintainer records the decision, unresolved objections, and any relevant conflict of interest. An AI assistant's review is not independent human review.

The project seeks feedback from operators, scanner authors, host maintainers, and the relevant MCP working groups. A public proposal or favorable comment does not confer foundation status. If SkillLatch later seeks AAIF hosting, governance and legal arrangements would be reviewed through the foundation's actual process.
